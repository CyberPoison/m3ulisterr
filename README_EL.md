## Ενημέρωση 14/09/2026

Ένα μεγάλο update για αξιοπιστία, γλώσσα, υπότιτλους, analytics και ασφάλεια. Κύρια σημεία:

- <strong>Πίνακας ελέγχου analytics M3uListerr (νέο):</strong> ένα αυτόνομο `dashboard.php` που καταγράφει και οπτικοποιεί κάθε αναπαραγωγή — μια διαδραστική υδρόγειο, γραφήματα και ένας πίνακας συνεδριών (sessions) που δείχνει τίτλο/αφίσα, ταινία vs τηλεοπτική σειρά, λογαριασμό, ζητούμενη & γλώσσα ήχου, την ακριβή έκδοση και υπηρεσία debrid που χρησιμοποιήθηκε, πρόοδο αναπαραγωγής (% και h:mm:ss), παρεχόμενους υπότιτλους, χώρα/πόλη/ISP, συσκευή και user-agent, IP, και χρόνο επίλυσης. Προστατεύεται με σύνδεση με ιδιωτικό αποθηκευτικό χώρο SQLite, συν έναν ενσωματωμένο επεξεργαστή `config.php` και διαχείριση διαπιστευτηρίων. Δείτε [Πίνακας ελέγχου analytics M3uListerr](#m3ulisterr-analytics-dashboard).
- <strong>Σωστή γλώσσα ήχου:</strong> εκδόσεις με πολλαπλούς ήχους δεν παίζουν πλέον σε λάθος γλώσσα. Το επιλεγμένο κομμάτι ήχου επιλέγεται τώρα από την κεφαλίδα του ίδιου του αρχείου (π.χ. μια έκδοση "ITA ENG" παίζει Αγγλικά, όχι Ιταλικά) και η ετικέτα HLS `LANGUAGE` αναφέρει τι πραγματικά παίζει αντί να ισχυρίζεται πάντα ότι είναι Αγγλικά.
- <strong>Γαλλικός λογαριασμός / `?lang=fr`:</strong> μια ειδική διαδρομή για Γαλλικά που δέχεται μόνο εκδόσεις όπου ο προεπιλεγμένος ήχος είναι πραγματικά Γαλλικά (επαληθευμένος από την κεφαλίδα του container, όχι μόνο από την ετικέτα), προτιμώντας αποθηκευμένα torrents και μια κλίμακα ποιότητας x264 1080p→720p→SD (`?codec=x265` γυρίζει σε μια κλίμακα πρώτα HEVC). Οι Γαλλικές ροές εξυπηρετούνται μέσω ενός ελαφριού byte-proxy (χωρίς ffmpeg) που επιλύει την πηγή μία φορά και κάνει stream εύρη (ranges), αποφεύγοντας τον περιορισμό IP (rate-limiting) από υπηρεσίες debrid.
- <strong>Υπότιτλοι:</strong> παρέχονται κομμάτια υποτίτλων τόσο σε Ευρωπαϊκά (pt-PT) όσο και σε Βραζιλιάνικα (pt-BR) Πορτογαλικά, με μια άμεση εναλλακτική (fallback) API του OpenSubtitles για όταν ο ενσωματωμένος πάροχος είναι εκτός λειτουργίας, και πλήρης υποστήριξη υποτίτλων για επεισόδια τηλεοπτικών σειρών.
- <strong>Σταθερότητα αναπαραγωγής:</strong> διορθώθηκαν διπλότυπα καρέ / ασυνέχειες χρονικής σήμανσης (timestamp discontinuities) στα όρια των τμημάτων (segments), και διορθώθηκε ένα σφάλμα εξάντλησης μνήμης που παρήγαγε σιωπηλά άδεια τμήματα (ατελείωτο buffering) σε πηγές 4K/remux υψηλού bitrate.
- <strong>Ενίσχυση ασφάλειας:</strong> αποκλείστηκε η δημόσια πρόσβαση σε ευαίσθητα αρχεία (`.git`, `cache.json`, καταγραφές (logs), `config.php`, τα ιδιωτικά δεδομένα του πίνακα ελέγχου), προστέθηκε ένας φρουρός SSRF στον video proxy, και μια αυστηρή Πολιτική Ασφάλειας Περιεχομένου (Content-Security-Policy), προστασία CSRF, σκλήρυνση συνεδρίας και κλείδωμα σύνδεσης στον πίνακα ελέγχου.

# Χαρακτηριστικά

- Δυναμική παραγωγή λιστών αναπαραγωγής για ζωντανή τηλεόραση, ταινίες και τηλεοπτικές σειρές
- Ενσωμάτωση με TMDB, Real Debrid, Premiumize και άμεσες πηγές για βελτιωμένη ανάκτηση περιεχομένου
- Εξομοίωση του λογισμικού Xtream Codes για πλήρεις λεπτομέρειες μεταδεδομένων
- Περίληψη πηγών Ζωντανής Τηλεόρασης όπως [Daddylive](https://href.li/?https://dlhd.so/24-7-channels.php), [TheTVApp](https://href.li/?https://thetvapp.to/), [MoveOnJoy](https://i.imgur.com/dFazdys.png), [Streamed Su Sports](https://href.li/?https://streamed.pk/), [Pluto TV](https://href.li/?https://downloads.pluto.tv/docs/pluto_tv_channels_listing.pdf) και άλλα.
- Τα περισσότερα από τα κανάλια ζωντανής τηλεόρασης περιλαμβάνουν λεπτομερείς πληροφορίες Οδηγού TV (EPG).
- Αυτόματη προσωρινή αποθήκευση (caching) των συνδέσμων ροής που βρέθηκαν για αποτελεσματική αναπαραγωγή
- 10.000 Πλήρους μήκους ταινίες ενηλίκων προστέθηκαν στο VOD (απενεργοποιημένο από προεπιλογή)
- Επιλογή σωστής γλώσσας ήχου για εκδόσεις με πολλαπλούς ήχους (διαβάζει την κεφαλίδα του αρχείου, όχι μόνο την ετικέτα)
- Ειδική Γαλλική διαδρομή (`UnlimitedFR` / `?lang=fr`) με επαληθευμένο από την κεφαλίδα Γαλλικό ήχο και μια κλίμακα ποιότητας με προτεραιότητα στη μνήμη cache
- Ευρωπαϊκά (pt-PT) και Βραζιλιάνικα (pt-BR) Πορτογαλικά κομμάτια υποτίτλων, με άμεση εναλλακτική (fallback) API OpenSubtitles
- Πίνακας ελέγχου analytics **M3uListerr**: στατιστικά αναπαραγωγής, μια διαδραστική υδρόγειο, γραφήματα και ένας πίνακας ανά συνεδρία (δείτε παρακάτω)

# Ξεκινώντας

[![Video Thumbnail](https://raw.githubusercontent.com/gogetta69/TMDB-To-VOD-Playlist/main/images/thumb.PNG)](https://rumble.com/embed/v54v3nx/?pub=4)

1. **Διαμόρφωση (Configuration)**: Ξεκινήστε ρυθμίζοντας το script με το απαιτούμενο δωρεάν [TMDB API Key](https://developer.themoviedb.org/docs/getting-started) και ένα προαιρετικό ιδιωτικό κλειδί για [Real Debrid](https://real-debrid.com/apitoken) ή [Premiumize](https://www.premiumize.me/account), τα οποία δεν είναι υποχρεωτικά.

2. **Ενσωμάτωση Xtream Codes**: Εισαγάγετε τη διεύθυνση IP ή το domain ως διακομιστή Xtream Codes. Οποιοδήποτε όνομα χρήστη και κωδικός πρόσβασης θα λειτουργήσουν, καθώς το script δεν απαιτεί έλεγχο ταυτότητας. Αυτό θα φορτώσει αυτόματα τις λίστες αναπαραγωγής Ζωντανής Τηλεόρασης, Ταινιών και Τηλεοπτικών Σειρών στην εφαρμογή.

3. **Εφαρμογές που δεν υποστηρίζουν Xtream Codes**: Αν η εφαρμογή σας δεν υποστηρίζει Xtream Codes, φορτώστε http://IP_ADDRESS/player_api.php?action=get_vod_streams (αντικαταστήστε το IP_ADDRESS με τη διεύθυνση IP του υπολογιστή σας) στον browser σας, εντοπίστε το `playlist.m3u8` στον ίδιο φάκελο με το script και φορτώστε το ως λίστα M3U. Σημειώστε ότι οι λίστες M3U8 είναι διαθέσιμες μόνο για ταινίες και ζωντανή τηλεόραση. Οι τηλεοπτικές σειρές δεν μπορούν να φορτωθούν ως λίστα M3U.

4. **Αναπαραγωγή**: Αφού ρυθμιστούν όλα και φορτωθούν οι λίστες αναπαραγωγής, θα πρέπει να μπορείτε να παίξετε ένα βίντεο. Κάνοντας κλικ στο κουμπί αναπαραγωγής το script θα αρχίσει να ψάχνει σε πολλούς ιστότοπους στο παρασκήνιο για έναν λειτουργικό σύνδεσμο. Παρακαλώ κάντε υπομονή και δώστε λίγο χρόνο για να βρεθεί ένας σύνδεσμος και να ξεκινήσει η ροή (streaming). Το script αποθηκεύει προσωρινά (caches) τον σύνδεσμο που βρέθηκε για περίπου 3 ώρες, εναρμονισμένο με την τυπική λήξη του access token των περισσότερων άμεσων πηγών, η οποία συμβαίνει στις 4 ώρες περίπου.

5. **Τοπική Φιλοξενία (Local Hosting)**: Εάν δεν έχετε μια εταιρεία φιλοξενίας για να τρέξετε αυτό το εξαιρετικά ελαφρύ script, μπορείτε να εγκαταστήσετε και να τρέξετε λογισμικό στον υπολογιστή σας, όπως το Xampp.

## Ανάπτυξη με Docker (Docker Deployment)

Μπορείτε πλέον να εκτελέσετε ολόκληρη τη στοίβα χρησιμοποιώντας Docker και Docker Compose.

### Προαπαιτούμενα
- Εγκατεστημένο Docker και Docker Compose.

### Γρήγορη Εκκίνηση (Quick Start)
1. Κλωνοποιήστε το αποθετήριο.
2. Διαμορφώστε το `config.php` (ή χρησιμοποιήστε μεταβλητές περιβάλλοντος για ορισμένες ρυθμίσεις).
3. Εκτελέστε την ακόλουθη εντολή στον ριζικό κατάλογο:
   ```bash
   docker-compose up -d
   ```
4. Αποκτήστε πρόσβαση στον ιστότοπο στο `http://localhost:8080`.

### GitHub Actions
Το έργο περιλαμβάνει μια ροή εργασιών του GitHub Actions `.github/workflows/deploy.yml` που δημιουργεί (builds) αυτόματα και ωθεί την εικόνα Docker στο GitHub Container Registry (GHCR) σε κάθε push στο `main`.

### Μεταβλητές Περιβάλλοντος
Οι ακόλουθες μεταβλητές περιβάλλοντος μπορούν να χρησιμοποιηθούν για τη ρύθμιση του container:
- `HEADLESSVIDX_ADDRESS`: Η διεύθυνση της υπηρεσίας HeadlessVidX (προεπιλογή: `localhost:3202`). Στο docker-compose, αυτό ορίζεται στο `headlessvidx:3202`.

# Πίνακας ελέγχου analytics M3uListerr

### Dashboard Screenshots

Το `dashboard.php` είναι ένας αυτόνομος πίνακας ελέγχου analytics και διαχείρισης, προστατευμένος με σύνδεση για τον διακομιστή. Καταγράφει ένα ελαφρύ γεγονός ανά αναπαραγωγή (γεγονότα resolve, playlist, segment, subtitle και proxy) σε ένα ιδιωτικό αρχείο καταγραφής, τα εισάγει σε μια τοπική βάση δεδομένων SQLite, και τα αποδίδει ως έναν σύγχρονο πίνακα ελέγχου.

### Τι δείχνει
- **Επισκόπηση** — συνολικές συνεδρίες, resolves, μοναδικοί θεατές και χώρες, μέσοι χρόνοι resolve και παράδοσης τμήματος, μετρήσεις hit/fail μνήμης cache, και ραβδογράμματα (bar charts) για υπηρεσία debrid που χρησιμοποιήθηκε, χώρα, συσκευή/player, λογαριασμό, γλώσσα, **ISP πελάτη** και **ταινίες vs τηλεοπτικές σειρές**.
- **Υδρόγειος** — μια διαδραστική 3D υδρόγειος που σχεδιάζει από πού ζητήθηκε κάθε ταινία/τηλεοπτική εκπομπή.
- **Συνεδρίες** — ένας πίνακας ανά αναπαραγωγή με αφίσα & τίτλο, **τύπο Ταινίας/TV και κωδικό επεισοδίου**, λογαριασμό (και τον κωδικό πρόσβασής του), ζητούμενη & γλώσσα ήχου, το ακριβές **όνομα κυκλοφορίας και τις γλώσσες της**, την **υπηρεσία debrid (AD/PM) και τον πάροχο**, **πρόοδο αναπαραγωγής** (% και το `h:mm:ss` που επιτεύχθηκε), τα προσφερόμενα κομμάτια υποτίτλων, χώρα + σημαία, πόλη/zip, **ISP πελάτη**, συσκευή, **user-agent** και IP, καθώς και το χρόνο resolve (ή δείκτη cache).
- **Τίτλοι** — οι ταινίες και οι τηλεοπτικές εκπομπές με τα περισσότερα αιτήματα ως πλέγμα αφισών.
- **Cache** — προβολή για τις καταχωρίσεις `cache.json` του resolver.
- **Ρυθμίσεις (Config)** — επεξεργαστείτε ένα επιτρεπόμενο σύνολο ρυθμίσεων του `config.php` από τον browser (γράφεται αντίγραφο ασφαλείας με χρονοσφραγίδα και γίνεται συντακτικός έλεγχος στο αρχείο πριν αντικατασταθεί).
- **Λογαριασμός** — αλλαγή ονόματος χρήστη και κωδικού πρόσβασης για τον πίνακα ελέγχου.

### Ασφάλεια
- Η πρώτη εκτέλεση σας προτρέπει να δημιουργήσετε έναν λογαριασμό διαχειριστή (admin), ο κωδικός πρόσβασης αποθηκεύεται κρυπτογραφημένος (Argon2id) σε μια ιδιωτική βάση δεδομένων SQLite, ποτέ στον κώδικα.
- Όλη η κατάσταση διατηρείται σε έναν ιδιωτικό κατάλογο `m3ulisterr_data/` που ο web server αρνείται να εξυπηρετήσει (SQLite DB, καταγραφή γεγονότων, συνεδρίες και ένα μυστικό ανά εγκατάσταση), αγνοείται από το git και δεν πρέπει ποτέ να γίνει commit.
- Μια αυστηρή Πολιτική Ασφάλειας Περιεχομένου (με nonce ανά απόκριση), tokens CSRF σε κάθε εγγραφή, δέσμευση συνεδρίας/timeouts και περιορισμός προσπαθειών σύνδεσης (login rate-limiting) προστατεύουν τον πίνακα ελέγχου. Οι βιβλιοθήκες γραφημάτων εξυπηρετούνται από τον δίσκο μετά τη σύνδεση αντί από οποιοδήποτε CDN.
- Ο γεωεντοπισμός IP (χώρα/πόλη/ISP) χρησιμοποιεί τη δωρεάν υπηρεσία ip-api.com, κάθε IP θεατή αναζητείται μία φορά και αποθηκεύεται στην προσωρινή μνήμη (cache).

### Ξεκινώντας
1. Αναπτύξτε τα αρχεία ως συνήθως (ο πίνακας ελέγχου δεν χρειάζεται επιπλέον ρύθμιση).
2. Βεβαιωθείτε ότι η εφαρμογή μπορεί να δημιουργήσει έναν εγγράψιμο κατάλογο `m3ulisterr_data/` δίπλα στον ιστότοπο (δημιουργείται αυτόματα όταν είναι εγγράψιμος).
3. Ανοίξτε το `http://YOUR_SERVER/dashboard.php`, δημιουργήστε τον λογαριασμό διαχειριστή, και συνδεθείτε. Τα δεδομένα εισάγονται στην πρώτη φόρτωση και κάθε φορά που πατάτε **Refresh data**.
