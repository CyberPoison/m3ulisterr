- <strong>استقرار التشغيل:</strong> تم إصلاح الإطارات المكررة / الانقطاعات الزمنية عند حدود المقاطع، وتم إصلاح خطأ استنفاد الذاكرة الذي أنتج بصمت مقاطع فارغة (تخزين مؤقت لا نهاية له) على مصادر 4K / remux ذات معدل البت العالي.
- <strong>تعزيز الأمان:</strong> منع الوصول العام إلى الملفات الحساسة (`.git`، `cache.json`، السجلات، `config.php`، البيانات الخاصة بلوحة التحكم)، تمت إضافة حارس SSRF إلى وكيل الفيديو، وسياسة Content-Security-Policy صارمة، وحماية من CSRF، وتقوية الجلسة وقفل تسجيل الدخول على لوحة التحكم.

# البدء

[![صورة مصغرة للفيديو](https://raw.githubusercontent.com/gogetta69/TMDB-To-VOD-Playlist/main/images/thumb.PNG)](https://rumble.com/embed/v54v3nx/?pub=4)

1. **التكوين**: ابدأ بإعداد البرنامج النصي باستخدام مفتاح واجهة برمجة تطبيقات [TMDB API Key](https://developer.themoviedb.org/docs/getting-started) المجاني المطلوب ومفتاح خاص اختياري لـ [Real Debrid](https://real-debrid.com/apitoken) أو [Premiumize](https://www.premiumize.me/account)، وهما غير إلزاميين.

2. **تكامل Xtream Codes**: أدخل عنوان IP أو المجال كخادم Xtream Codes. سيعمل أي اسم مستخدم وكلمة مرور نظرًا لأن البرنامج النصي لا يتطلب مصادقة. سيؤدي هذا تلقائيًا إلى تحميل قوائم تشغيل البث التلفزيوني المباشر والأفلام والمسلسلات التلفزيونية في التطبيق.

3. **التطبيقات التي لا تدعم Xtream Codes**: إذا كان تطبيقك لا يدعم Xtream Codes، فقم بتحميل http://IP_ADDRESS/player_api.php?action=get_vod_streams (استبدل IP_ADDRESS بعنوان IP لجهاز الكمبيوتر الخاص بك) في متصفحك، ثم حدد موقع `playlist.m3u8` في نفس المجلد الذي يوجد به البرنامج النصي وقم بتحميله كقائمة تشغيل M3U. لاحظ أن قوائم تشغيل M3U8 متاحة للأفلام والبث التلفزيوني المباشر فقط؛ لا يمكن تحميل المسلسلات التلفزيونية كقائمة تشغيل M3U.

4. **التشغيل**: بمجرد إعداد كل شيء وتحميل قوائم التشغيل، يجب أن تكون قادرًا على تشغيل مقطع فيديو. سيؤدي النقر فوق زر التشغيل إلى تشغيل البرنامج النصي للبحث في مواقع ويب متعددة في الخلفية عن رابط قابل للتشغيل. يرجى التحلي بالصبر وإتاحة بعض الوقت للعثور على رابط وبدء البث. يقوم البرنامج النصي بتخزين الرابط الذي تم العثور عليه مؤقتًا وحفظه لمدة 3 ساعات تقريبًا، بما يتماشى مع انتهاء صلاحية الرمز المميز للوصول النموذجي لمعظم المصادر المباشرة، والذي يحدث في حوالي 4 ساعات.

5. **الاستضافة المحلية**: إذا كنت تفتقر إلى شركة استضافة لتشغيل هذا البرنامج النصي الخفيف الوزن للغاية، فيمكنك تثبيت وتشغيل برامج على جهاز الكمبيوتر المكتبي الخاص بك مثل Xampp.

## النشر عبر Docker

يمكنك الآن تشغيل الحزمة بأكملها باستخدام Docker و Docker Compose.

### المتطلبات الأساسية
- تثبيت Docker و Docker Compose.

### البدء السريع
1. استنسخ المستودع.
2. قم بتكوين `config.php` (أو استخدم متغيرات البيئة لبعض الإعدادات).
3. قم بتشغيل الأمر التالي في الدليل الجذر:
   ```bash
   docker-compose up -d
   ```
4. قم بالوصول إلى موقع الويب على `http://localhost:8080`.

### إجراءات GitHub Actions
يتضمن المشروع سير عمل GitHub Actions في `.github/workflows/deploy.yml` والذي يقوم تلقائيًا بإنشاء صورة Docker ودفعها إلى سجل حاويات GitHub (GHCR) عند كل دفع إلى `main`.

### متغيرات البيئة
يمكن استخدام متغيرات البيئة التالية لتكوين الحاوية:
- `HEADLESSVIDX_ADDRESS`: عنوان خدمة HeadlessVidX (الافتراضي: `localhost:3202`). في docker-compose، يتم تعيين هذا إلى `headlessvidx:3202`.

# لوحة تحكم تحليلات M3uListerr

`dashboard.php` عبارة عن لوحة تحكم وتحليلات مستقلة ومحمية بتسجيل دخول للخادم. إنها تسجل حدثًا خفيفًا واحدًا لكل تشغيل (أحداث الدقة، وقائمة التشغيل، والمقاطع، والترجمة، والوكيل) في سجل خاص، وتستوردها إلى قاعدة بيانات SQLite محلية، وتعرضها كلوحة معلومات حديثة.

### ماذا تعرض
- **نظرة عامة** — إجمالي الجلسات، عمليات الاستجابة، المشاهدين الفريدين والبلدان؛ متوسط أوقات الاستجابة وتسليم المقاطع؛ عدد مرات نجاح/فشل ذاكرة التخزين المؤقت؛ ومخططات شريطية لخدمة debrid المستخدمة، البلد، الجهاز/المشغل، الحساب، اللغة، **مزود خدمة الإنترنت للعميل** و **الأفلام مقابل البرامج التلفزيونية**.
- **الكرة الأرضية** — كرة أرضية ثلاثية الأبعاد تفاعلية ترسم من أين تم طلب كل فيلم/برنامج تلفزيوني.
- **الجلسات** — جدول لكل تشغيل مع الملصق والعنوان، **نوع الفيلم/التلفزيون ورمز الحلقة**، الحساب (وكلمة المرور الخاصة به)، اللغة المطلوبة والصوتية، **اسم الإصدار الدقيق ولغاته**، **خدمة debrid (AD/PM) والمزود**، **تقدم التشغيل** (النسبة المئوية و `h:mm:ss` التي تم الوصول إليها)، مسارات الترجمة المعروضة، البلد + العلم، المدينة/الرمز البريدي، **مزود خدمة الإنترنت للعميل**، الجهاز، **وكيل المستخدم** وعنوان IP، ووقت الاستجابة (أو علامة التخزين المؤقت).
- **العناوين** — الأفلام والبرامج التلفزيونية الأكثر طلبًا كشبكة ملصقات.
- **ذاكرة التخزين المؤقت** — عارض لإدخالات `cache.json` الخاصة بالمحلل.
- **التكوين** — تحرير مجموعة مسموح بها من إعدادات `config.php` من المتصفح (يتم كتابة نسخة احتياطية مختومة بمرور الوقت ويتم التحقق من بناء جملة الملف قبل استبداله).
- **الحساب** — تغيير اسم مستخدم وكلمة مرور لوحة التحكم.

### الأمان
- يطالبك التشغيل الأول بإنشاء حساب مسؤول؛ يتم تخزين كلمة المرور مجزأة (Argon2id) في قاعدة بيانات SQLite خاصة، ولا يتم تخزينها في الكود أبدًا.
- يتم الاحتفاظ بجميع الحالات في دليل `m3ulisterr_data/` خاص يرفض خادم الويب تقديمه (قاعدة بيانات SQLite، سجل الأحداث، الجلسات وسر التثبيت)؛ يتم تجاهله في git ويجب عدم الالتزام به أبدًا.
- سياسة Content-Security-Policy صارمة (مع رقم خاص بكل استجابة)، وعلامات CSRF في كل عملية كتابة، وتقييد الجلسة/مهلة الجلسة وتقييد معدل تسجيل الدخول تحمي لوحة التحكم. يتم تقديم مكتبات المخططات المجمعة من القرص بعد تسجيل الدخول بدلاً من أي شبكة توصيل محتوى (CDN).
- يستخدم تحديد الموقع الجغرافي لعنوان IP (البلد/المدينة/مزود خدمة الإنترنت) خدمة ip-api.com المجانية؛ يتم البحث عن عنوان IP لكل مشاهد مرة واحدة وتخزينه مؤقتًا.

### البدء
1. قم بنشر الملفات كالمعتاد (لا تحتاج لوحة التحكم إلى إعداد إضافي).
2. تأكد من أن التطبيق يمكنه إنشاء دليل `m3ulisterr_data/` قابل للكتابة بجوار الموقع (يتم إنشاؤه تلقائيًا عندما يكون قابلاً للكتابة).
3. افتح `http://YOUR_SERVER/dashboard.php`، وقم بإنشاء حساب المسؤول، وسجل الدخول. يتم استيراد البيانات عند التحميل الأول وكلما ضغطت على **تحديث البيانات** (Refresh data).

# إخلاء مسؤولية قانوني

يقوم هذا البرنامج النصي باسترداد معلومات الأفلام من TMDB والبحث عن المحتوى ذي الصلة على مواقع ويب تابعة لجهات خارجية. قانونية بث أو تنزيل المحتوى من خلال هذه المواقع غير مؤكدة. يرجى توخي الحذر والنظر في الآثار القانونية والأخلاقية لاستخدام هذا البرنامج النصي للوصول إلى المحتوى المحمي بحقوق الطبع والنشر واستهلاكه. احترم دائمًا قوانين حقوق الطبع والنشر وشروط الخدمة الخاصة بالمواقع التي تزورها.
